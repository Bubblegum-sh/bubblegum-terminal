# Terminal Flamingo

A native macOS app (14+) for running several Claude Code sessions side by side in one window.
Each session is a real terminal (SwiftTerm) running `claude` in a project folder, launched through
your login shell. Live status comes from Claude Code's official hooks, never from parsing output.

## Build and run

Requires Xcode 15+ installed (SwiftUI's macros ship with Xcode, not with the Command Line Tools alone).

```sh
scripts/build-app.sh            # → build/Terminal Flamingo.app (universal, ad-hoc signed)
open "build/Terminal Flamingo.app"
scripts/test.sh                 # unit tests (hook install/merge, event parsing, statuses, sidebar, launch)
```

The scripts set `DEVELOPER_DIR` to `/Applications/Xcode.app` automatically if `xcode-select`
points at the Command Line Tools. For an Xcode project: `xcodegen generate` (uses `project.yml`).

## Layout

| Path | What |
| --- | --- |
| `Sources/TerminalFlamingoCore` | UI-free logic: `Session`/statuses, hook installer + settings merge, hook event parsing and status reducer, event folder watcher, sidebar grouping/search, launch command, persistence |
| `Sources/TerminalFlamingo/Services` | `SessionStore` (source of truth), `TerminalRegistry` (one cached terminal per session), `Notifier`, `AppSettings` |
| `Sources/TerminalFlamingo/Views` | Sidebar, rows, detail toolbar + terminal host, quick switcher, settings, hook sheet |
| `Sources/TerminalFlamingo/Theme` | Dark/light design tokens (spec §8) — views never use raw hex |
| `Resources` | `Info.plist`, `AppIcon.appiconset` (generated by `scripts/make-icon.swift`) |

## Files on disk

- `~/Library/Application Support/TerminalFlamingo/sessions.json` — sessions (atomic writes)
- `~/Library/Application Support/TerminalFlamingo/hook.sh` — hook script (no-op unless `TF_SESSION_ID` is set)
- `~/Library/Application Support/TerminalFlamingo/events/` — transient hook events
- `~/.claude/settings.json` — hook entries merged in on "Install hooks"; backed up to `settings.json.tf-backup` first

## Development aids (debug builds)

- `TF_SUPPORT_DIR=/some/dir` uses another folder for sessions/events instead of Application Support;
  "Install hooks" then writes to `/some/dir/claude/settings.json` (or `TF_CLAUDE_DIR`), never the real `~/.claude`.
- `TF_SNAPSHOT=/tmp/shot TF_SNAPSHOT_STEPS=main,switcher,clear,search,rename,light` renders window snapshots, then quits.
